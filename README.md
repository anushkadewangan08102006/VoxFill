VoxFill 🎙️

VoxFill is a Chrome extension that makes online forms more accessible for visually impaired users through voice-based interaction. It scans forms, asks for the required information conversationally, and fills the fields using browser-based Speech APIs while keeping the user in control of submission.

✨ Features
🎙️ Voice-based form filling
♿ Accessibility-focused design
🇮🇳 Hindi voice input for English forms
💬 Conversationally handles unfilled fields
🔊 Speech recognition & text-to-speech
🔒 No automatic form submission
⚡ Built with Chrome Extension Manifest V3
🛠️ Tech Stack

JavaScript • HTML/CSS • Manifest V3 • Web Speech API

🚀 Upcoming: Smart Form Assistant

We are also working on a feature that helps users understand confusing form fields while filling them. Instead of watching long tutorial videos, users can use VoxFill alongside the webpage to get field explanations, word meanings, and real-time guidance.

🎯 Vision

Helping users understand and fill online forms through simple voice-based assistance.
